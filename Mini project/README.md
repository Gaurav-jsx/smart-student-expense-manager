# SmartSpend 💰 — Student Expense & Transparent Family Guidance

> **Hackathon-Winning Build** — The offline-first, dual-role financial management platform designed for Indian B.Tech college students and their parents. It tells students what they can **safely spend today** while giving parents **transparent, consent-based visibility** across devices.

Built with **100% Vanilla HTML5, CSS3, and JavaScript** — zero build tools, zero frameworks, zero external CDNs, zero npm packages. Works right out of the box by double-clicking `index.html` (`file://`), running on Live Server, or hosting on GitHub Pages / Firebase Hosting.

## ⚡ Next-Level Features

### 1. 🛡️ Safe-to-Spend Today Hero Card
- Live-updating daily allowance computed using:
  $$\text{Safe Today} = \frac{\max(0, \text{Monthly Budget} - \text{Spent Before Today})}{\text{Days Left in Month}}$$
- Immediate color state alerts (Green $\to$ Amber $\to$ Red) when daily quota is exceeded.
- Daily spending trajectory sparkline with target daily allowance threshold line.

### 2. 📱 Indian Bank & UPI SMS Paste Importer
- Zero-dependency regex parser supporting **SBI, HDFC, ICICI, Paytm, PhonePe, and Google Pay**.
- Extracts amount, merchant, date, UPI reference number, and auto-assigns student categories (Food, Travel, Education, Bills, Shopping, Entertainment).
- Rejects credit SMS and OTP security notices safely.

### 3. 🤔 "Can I Afford It?" Purchase Simulator
- Simulates the consequences of a planned purchase *before* spending.
- Recalculates today's daily safe allowance and month-end trajectory.
- Automatically calculates delay impact on active student savings goals (e.g. *"This purchase equals ~2.4 weeks of contributions toward your Coding Laptop goal"*).

### 4. 🔥 Year-at-a-Glance Spending Heatmap
- Pure SVG GitHub-style calendar heatmap displaying spending frequency and volume across the entire year with interactive date tooltips.

### 5. 🎮 Gamification & Financial Literacy Hub
- **XP Progression Ladder**: Starter XP $\to$ `Saver Sprout 🌱` (Level 1) $\to$ `Budget Boss 💼` (Level 2) $\to$ `Money Master 🏆` (Level 3).
- **Daily Rotating Tips**: Curated bank of 30+ practical Indian college financial tips (student discounts, second-hand books, UPI Lite, hostel splits).
- **Weekly Literacy Quiz**: Interactive 3-question quiz reinforcing responsible money habits.

### 6. 🤝 Consent-Based Parent-Child Linking
- **Unguessable 8-Character Invite Codes**: Generated by the student, expiring in 15 minutes, single-use only.
- **Two Privacy Modes Controlled by Student**:
  - **Full Transparency**: Parent views transaction history, dates, and notes.
  - **Summary Only**: Polite privacy mode where parent views category totals and budget progress, but individual transaction details and merchant names are masked to respect student independence.
- **Immediate Revocation**: Student can revoke parental access at any moment with 1 click.

### 7. 👨‍👩‍👧 Parent Dashboard & Advisory Controls
- **Family Spending Digest**: Real-time family overview across all linked children.
- **Inbox for Requests & Alerts**: Instant approval or decline of extra allowance requests; approved funds are idempotently credited to the child's monthly budget.
- **Advisory Parental Controls**: Recommended allowance, large expense alert threshold, and category caps. UI clearly highlights that limits are guidance recommendations, not bank payment blocks.
- **Parent-Child Challenges**: Parents propose fun financial goals (e.g. *"Canteen Cap: Keep Canteen under ₹150/day for 7 days"*) rewarding students with bonus allowance.
- **Printable Weekly Report**: Clean, high-contrast printable summary formatted via CSS `@media print`.

## 🏛️ Architecture & Dual-Adapter Data Layer

SmartSpend uses an interchangeable Data Layer abstraction (`SS.repo` and `SS.auth`) that delegates to either adapter without the UI knowing which is active:

```
                      ┌───────────────────────────────┐
                      │    UI View Layer (SPA)        │
                      │ (Auth, Student, Parent, Child)│
                      └──────────────┬────────────────┘
                                     │ calls
                      ┌──────────────▼────────────────┐
                      │    SS.repo  /  SS.auth        │
                      └───────┬───────────────┬───────┘
                              │               │
            ┌─────────────────┴─┐           ┌─┴─────────────────┐
            │ SS.adapters.local │           │SS.adapters.firebase│
            └─────────┬─────────┘           └─────────┬─────────┘
                      │                               │
         ┌────────────▼──────────┐         ┌──────────▼──────────┐
         │      localStorage     │         │ Firebase Auth &     │
         │ (PBKDF2 SHA-256 >=100k│         │ Cloud Firestore     │
         │  In-Tab Bus + storage)│         │ (Multi-device sync) │
         └───────────────────────┘         └─────────────────────┘
```

1. **Local Demo Mode (Default)**:
   - When `firebase-config.js` is null, runs completely offline inside `localStorage`.
   - Simulates multi-account authentication with passwords hashed using `crypto.subtle` PBKDF2 (SHA-256, >=100,000 iterations, per-user salt).
   - Real-time parent $\leftrightarrow$ student updates simulated across open browser tabs via an in-memory event bus and the native `storage` window event.
   - Pre-seeded with 1-click demo accounts: **Aarav (Student)** and **Mr. Sharma (Parent)** with 90 days of linked transactions.
2. **Cloud Mode (Multi-Device)**:
   - When Firebase credentials are added to `firebase-config.js`, the pinned Firebase 10.12.5 compat SDK is dynamically loaded.
   - Enables real-time synchronization across different physical devices (phone, laptop, desktop) via Firestore `onSnapshot`.
   - Offline persistence enabled via `enablePersistence()`.

## 🚀 Quick Start Guide

### Option 1: Direct Browser Launch (Local Demo Mode — Zero Setup)
1. Double click `index.html` in any modern web browser (or serve with VS Code Live Server).
2. On the login screen, click **"Demo Student – Aarav"** or **"Demo Parent – Mr. Sharma"** to enter the app instantly with pre-seeded data.
3. Open a second window to test real-time parent-child interactions!

### Option 2: 10-Minute Firebase Cloud Setup (Multi-Device Sync)
1. Go to the [Firebase Console](https://console.firebase.google.com/) and create a free project on the **Spark (free) plan**.
2. Under **Build $\to$ Authentication**, enable the **Email/Password** sign-in provider.
3. Under **Build $\to$ Firestore Database**, click **Create database** (start in Test mode).
4. Copy the rules from `firestore.rules` and paste them into the Firestore **Rules** tab, then click **Publish**.
5. In Project Settings, scroll to **Your apps**, click the Web icon (`</>`), and register an app.
6. Open `firebase-config.js` in this workspace and replace `null` with your Firebase config object:
   ```javascript
   window.SS_FIREBASE_CONFIG = {
     apiKey: "AIzaSy...",
     authDomain: "smartspend-demo.firebaseapp.com",
     projectId: "smartspend-demo",
     storageBucket: "smartspend-demo.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abcdef"
   };
   ```
7. Reload `index.html`. SmartSpend will automatically detect the config, load the Firebase 10.12.5 compat SDK, and activate Cloud Multi-Device Sync!

## 🔒 Security & Privacy Commitments

1. **Role Immutability**: A user's role (`student` or `parent`) is locked at account creation and can never be escalated or modified via the client.
2. **Transparent Consent**: Student financial records can only be read by parents who have an active link document (`links/{childUid_parentUid}`). Students can switch to "Summary Only" mode or revoke access at any time.
3. **No Plaintext Passwords**: In Local Demo Mode, all passwords are cryptographic hashes derived with `crypto.subtle` PBKDF2 (SHA-256, $\ge 100,000$ iterations) with per-user salts.
4. **Content Security Policy**: Hardened CSP restricting all script and connection endpoints strictly to `'self'` and Google Firebase servers.
